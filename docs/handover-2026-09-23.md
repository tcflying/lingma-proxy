## 2. 复盘：09-18 → 09-22 干了什么（按轮次）

### 第一阶段：救活（09-18 ~ 09-19，原会话）

- **诊断**：新版 Qoder CN 推理网关只认客户端内 WASM `prepareRequest` 签名，Go 侧重放
  一律 403/503；旧 cosy 凭据不再落盘。结论：**任何"Go 里重放网关请求"都是死路**。
- **方案**：新增 `qodercli` 后端（`internal/qodercli/`）——spawn 桌面版自带 CLI/worker
  runtime 子进程，签名交给客户端自己。凭据链全本地：DPAPI 解 `Local State` →
  `auth.v1.dat` device token → `/api/v1/me/jobToken` → 注入子进程环境变量。
- 推到私有仓库 `tcflying/lingma-proxy`；四家客户端（ZCode / MiniMax Code /
  opencodex(Codex) / DSH）接入。
- **档位体系定稿**（反复推翻两次才钉死）：档位是**每个模型一套**，不是全局梯子；
  Qwen3.8-Flash 实际只有 `none/low/medium/xhigh`；**不传档 ≠ 关思考**（比 xhigh 更费）。
- 拆成三个单二进制变体：`cn`(8095) / `intl`(9095) / `both`(10095)，同一份代码零分支，
  由打包脚本注入站点配置。

### 第二阶段：稳定性（09-20）

- 鉴权握手网络抖动被报成裸 500（客户端判不可重试）→ `ErrTransientUpstream` 哨兵 →
  可重试 503；端口收敛为**本机只跑 10095**。
- 历史图片把会话钉死（`requestHasImages` 扫全历史而非当前轮）+ 登录态失效时
  CLI 侧旧缓存报 `token is not active`（CN 桌面端其实还是登录态）→ 修复 + 文案。
- `/v1/models` 两站点**串行**探测 7.8s，客户端超时误判假 500 → 并行化 + 列表缓存。
- **239"黑窗闪退"真因**：服务方式启动不进交互会话，DPAPI 拿不到主密钥 →
  解法：WinRM + `Register-ScheduledTask -LogonType Interactive` 拉进 console 会话。

### 第三阶段：正确性大审查（09-21）

用户症状："别的 IDE 接代理，回复老带 tool calling，或话没说完就断"。派子代理全局
审查 + 翻代理实盘流量，实锤三条根因并全部落地（`b835420` + `1e108da`）：

1. **过滤器和解析器两套标准**（两症状共同来源）：流式过滤器认为"块开始"的标准比
   解析器宽，且 `blocked` 永久吞增量。修法：抽 `matchActionBlock` 唯一判定，
   过滤器改状态机（块前散文照流、块按字节区间丢、块后继续、未闭合当散文放回）。
   **铁律：以后动解析器必须同时动过滤器，两边共用同一把尺子。**
2. **被杀/取消的 CLI 子进程被当成功**（半句话 + HTTP 200）：只有见过 `result` 帧
   才允许在非零退出下报成功。
3. **假流式**：整轮只在结束时 emit 一个 delta，首字 51.3s。加 `--print
   --include-partial-messages` 拿真增量（首字 10.2s）+ 正文前每 15s 一个 SSE ping。
4. **XML 方言工具调用**（ZCode 实测头号主因：库里 200 处 vs 代理自有围栏 1 处）：
   `scanXMLBlock` 手写解析，两种方言统一校验，参数按 schema 回正类型，半截标签不漏。
5. 顺带：qodercli 支持**图片输入**（`userFrame` image block，只保留当前轮附件）；
   `finish_reason` 改读 result 帧真实 `stop_reason`（6 处硬编码全换）。

### 第四阶段：收尾修复（09-21 深夜 ~ 09-22 早，`cb94e1f`→`370d30d`）

审查清单逐条回代码核实（**三条复查为假，不在做**：`RLock 下广播`、`error_max_turns`
（`--tools "" --max-turns 1` 下不可达）、`app.go:2198` 配置清零（每字段有非空守卫）），
真问题修掉：

- `truncateRecordedString` 空转（1.29GB RSS 主因）→ 8 KiB 截断、rune 边界。
- 每请求整份打印请求体（含图片）到 stdout → 删。
- DPAPI use-after-free（`LocalFree` 后返回值还指着那块内存）→ 先 copy 再 free。
- `tool_choice:"none"` 只挡注入没挡解析 → 两边同一开关。
- `remote.Client` 把探测结果写进共享 `c.cfg.BaseURL`（并发 chat 正读同字段）→
  可变域名收进 `base+baseMu`，探测显式传参。
- `ensureConnected` 全程持 `s.mu` 走拨号（一次慢重连冻住所有端点）→ `connectMu`
  只串行化握手，锁序 connectMu → mu。
- 桌面端"先探测再 ListenAndServe"的 TOCTOU → 绑一次直接 `Serve(ln)`。

### 第五阶段：Web 控制台（09-22 15:2x，`1941a13`）

- 用户要"完整可写版 webui"。设计要害：**控制面不能挂在代理端口上**——
  `UpdateConfig` 内部就是 `StopProxy()+StartProxy()`，同监听会自杀。所以独立端口
  = 代理端口+1（10095→10096）。
- `desktop/control.go`：读 `/api/admin/{version,status,config,detection,models,stats,
  console,requests,requests/detail,logs,logs/detail}`，写 `POST {config,models/refresh,
  models/select,requests/clear,logs/clear,proxy/{start,stop,restart}}`，全部直调现有
  App 方法零重写。Bearer token（per-install 32hex）门禁，SSE 额外允许 `?token=`。
- `browserBridge.js`：无 `window.go` 时装同名代理转 fetch，5 个 Vue 视图一行未改。
- 同轮抓到的大 bug：**app-state 文件膨胀到 214MB**（8KiB 上限只管新记录，旧全量记录
  被无限读回写回）→ 上限挪到"往外写的关口"，214MB → 3.4MB。
- 注意：这个提交混了控制台 + 持久化上限两件事（按文件 git add，app.go 两边都沾），
  已选择不拆历史。

## 6. 已知坑（接手前必读）

1. **Bash 里内联 PowerShell 的 `$` 会被转义吞**——写 .ps1 脚本文件执行，跑完删。
2. **`python` 解析到 LibreOffice 内嵌 python**（PATH 第一位）——显式用
   `C:/Users/Administrator/AppData/Local/Programs/Python/Python312/python.exe`。
3. **Git Bash 的 `{ ...; }` 不是子 shell**，块里 `cd` 会漏到后续命令——曾因此把
   239 共享上的 zip 意外覆盖（字节相同无损失，但属于计划外网络盘写入）。
4. **在回复正文里写出工具调用标签的字面量会被自己的解析层当真触发**——涉及
   XML/action 标签一律拼接或中文描述，不贴原文。
5. **引用实测前必须 Read 对应输出文件本身**——曾两次把别的运行结果读串当成复现。
6. **"zip 名字对上了" ≠ "里面 exe 是新的"**——校验永远回读哈希，三处（zip 内、
   Release 资产、239 落盘）都要。
7. 含口令的临时脚本用完即删，`grep -rl` 复查零残留后再收工。
8. **手工 `go build` 不重新生成 `wailsjs` 绑定**（只有 `wails build` 会）。给 App 加新方法后，
   前端要调它只能走 `window.go.main.App.X()`；写成 `import { X } from 'wailsjs/.../App.js'`
   会让 `npm run build` 直接报“未导出”，比运行时错误更早也更吵。
9. **别在 `printf` 的格式串里放 Go 的 `%v`**：bash 的 printf 会当格式符报错，而
   `printf ... >> file` 的重定向**在报错前就已把文件打开追加**，留下半截内容——
   本轮就据此把一段被截断的重复函数追加进了 `control.go`。要写文件用 Write/Edit。
